# FlightLab Roof

**Dachaufmaß, Konturen und 3D-Modell aus Drohnenbildern. Vollständig offline, unbefristete Lizenz.**

Dieses Repository dient allein der Auslieferung. Es enthält keinen Quelltext —
nur die fertige Installationsdatei unter *Releases*.

## Herunterladen

**[FlightLab Roof herunterladen](https://github.com/oisxeng/flightlab-roof/releases/latest/download/FlightLabRoof-setup.exe)**

Diese Adresse zeigt immer auf die neueste Fassung.

Die Testfassung läuft **14 Tage mit vollem Funktionsumfang** — rechnen, messen,
ausgeben. Keine Anmeldung, keine E-Mail-Adresse, keine Zahlungsdaten.

## Systemvoraussetzungen

| | |
|---|---|
| Betriebssystem | Windows 10 oder 11, 64 Bit |
| Arbeitsspeicher | 16 GB, mehr schadet nicht |
| Grafikkarte | NVIDIA mit CUDA, empfohlen 8 GB Grafikspeicher, Untergrenze 2 GB. Ohne NVIDIA-Grafikkarte wird nicht gerechnet. |
| Festplatte | SSD; beim Rechnen rund 225 MB je Aufnahme, also rund 7 GB bei 30 und rund 18 GB bei 80 Aufnahmen |
| Internet | nicht erforderlich — auch nicht zum Freischalten |
